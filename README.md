# LeadsAgenciaCnw-publico

Repositório de distribuição de atualizações do AgenciaCnw Leads (build público).

Este repositório é usado apenas como destino de releases do GitHub — os
instaladores publicados aqui são baixados automaticamente pelo próprio
programa (via `electron-updater`) para verificar e aplicar atualizações.

Não há código-fonte aqui de propósito. O código-fonte fica no repositório
privado `LeadsAgenciaCnw-Admin`.
